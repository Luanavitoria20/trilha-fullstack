## ▶️ Como executar os exercícios

Para executar os arquivos JavaScript, é necessário ter o [Node.js](https://nodejs.org/) instalado.

**1. Clone o repositório:**

```bash
git clone https://github.com/Luanavitoria20/trilha-fullstack.git
```

**2. Entre na pasta do projeto:**

```bash
cd trilha-fullstack
```

**3. Execute uma aula:**

```bash
node logica/aula01.js
```

Para executar outro exercício, substitua o nome do arquivo pelo arquivo que deseja estudar.
